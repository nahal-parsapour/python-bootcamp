# 🐍 Python Bootcamp

A hands-on Python learning journey from programming fundamentals to backend development.
This repository contains my exercises, practice projects, and experiments as I progress through a Python Bootcamp.

> Learning never ends. This repository is a record of the journey, not the destination.
---

## 🎯 Goal

The main goal of this repository is to build a solid and practical foundation in:

* Python programming
* Problem solving and algorithms
* Object-Oriented Programming
* File handling and regular expressions
* Package and dependency management
* Web scraping
* Automated testing
* SQL and databases
* Linux fundamentals
* Web development foundations
* Backend development concepts

The learning path starts from the basics and gradually moves toward more practical software development topics.

## 🧪 Learning Approach

This repository is intentionally practice-oriented.

Instead of only studying concepts theoretically, I try to reinforce each topic through:

* Coding exercises
* Small programs
* Problem solving
* Refactoring
* Testing
* Experimentation
* Working with real Python tools
* Gradually improving project structure

The code may not always represent the most advanced or production-ready solution. That is intentional.

The purpose of this repository is to **document learning and improvement over time**.
